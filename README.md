Primer artefacto funcional público de AUREA OS. Un laboratorio navegable que demuestra la arquitectura completa mediante evidencia.

## Arquitectura
Daniel → AUREA OS → Mission → Agents → Workflow → Quality Control → Evidence Ledger → Learning → Reusable Capability → AUREA OS

## Ejecutar Local
1. Clona el repo
2. Abre `index.html` en Chrome

## Desplegar en Vercel
1. Sube estos archivos a GitHub
2. Ve a vercel.com → New Project → Import GitHub Repo
3. Framework: Other
4. Deploy

## ¿Qué es REAL en v0.2?
- Navegación web responsive
- Workflow local con estados
- Persistencia con localStorage
- Evidence Ledger
- Learning Loop
- Quality Gate de demostración
- Contadores de Compounding

- El workflow es simulado con pausas
